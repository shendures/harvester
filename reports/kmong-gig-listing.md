## 상세 설명

### 이런 고민 있으신가요?

- 스마트스토어에서 지금 내가 최저가인지 하루에도 몇 번씩 직접 확인하고 계신가요?
- 경쟁사·거래처 가격을 매일 하나하나 열어보고 엑셀에 옮기는 데 시간을 쓰고 계신가요?
- 예전에 크몽에서 크롤링 프로그램을 맡겼는데, 사이트가 바뀐 뒤로 개발자와 연락이 끊긴 경험이 있으신가요?

수작업으로 가격을 확인하는 사이, 경쟁사가 가격을 내리면 대응이 늦어져 노출 순위와 매출에 영향을 줄 수 있습니다. 저는 이 문제를 "한 번 쓰고 끝나는 스크립트"가 아니라 **직접 운영할 수 있는 프로그램**으로 해결해 드립니다.

### 무엇을 만들어 드리나요

지정하신 웹사이트(정적 HTML, JS 렌더링 사이트, REST API, XML까지 대응)에서 원하시는 데이터를 자동으로 수집하는 Windows용 프로그램(.exe)을 제작해 드립니다. GUI로 구성되어 있어 코드를 몰라도 직접 실행·스케줄링·결과 확인이 가능하고, 결과는 CSV나 DB로 받아보실 수 있습니다.

### 다른 곳과 다른 점

**1. 재의뢰가 생겨도 방치되지 않습니다.**
크롤링 프로그램은 대상 사이트 구조가 바뀌면 손봐야 할 일이 생깁니다. 이건 어느 개발자가 만들어도 마찬가지입니다. 문제는 그다음입니다 — 저가 단건 작업은 이 시점에 담당자와 연락이 끊기는 경우가 실제로 많습니다(크몽에서 직접 크롤러를 팔던 개발자가 유지보수 부담을 못 이겨 판매를 중단한 사례, 개발 외주 피해 후기 등에서 반복적으로 확인되는 패턴입니다). 저는 유지보수 계약으로 대응 시점과 범위를 사전에 정해드리기 때문에, 사이트가 바뀌었을 때 방치되는 일이 없습니다.

**2. 한 번 쓰고 버리는 스크립트가 아니라 운영 가능한 프로그램입니다.**
납품 후에도 GUI에서 직접 재실행·스케줄링(일/주/월 단위 무인 실행)·수집 결과 정제 규칙 조정이 가능합니다.

**3. 로그인이 필요한 사이트, JS로 동작하는 사이트도 지원합니다.**
일반적인 노코드 크롤링 툴이나 저가 스크립트로는 대응이 안 되는 구조에도 대응합니다.

### 참고해 주세요 — 지금은 사이트 1개 기준입니다

여러 사이트를 하나의 프로그램으로 동시에 모니터링하는 통합 기능은 현재 준비 중입니다. 지금은 사이트 1개를 기준으로 프로그램을 제작해 드리고, 사이트가 여러 개 필요하시면 사이트별로 각각 제작해 드립니다(2번째 사이트부터 할인 적용 — 문의 시 안내).

### 진행 방식

요구사항 확인 → 견적 → 계약(선금·잔금) → 개발 → 결과물 검수 → 프로그램+매뉴얼 납품 → 하자보수 → (필요 시) 유지보수 계약

## FAQ

**Q. 여러 사이트를 한 프로그램으로 동시에 모니터링할 수 있나요?**
현재는 프로그램 1개당 사이트 1개를 기준으로 제작해 드립니다(통합 모니터링 기능은 준비 중입니다). 여러 사이트가 필요하시면 사이트별로 각각 제작해 드리며, 2번째 사이트부터 할인해 드립니다.

**Q. 대상 사이트 구조가 바뀌면 또 처음부터 의뢰해야 하나요?**
구조 변경 대응에는 코드 수정이 필요한 게 사실입니다. 다만 유지보수 계약을 맺어두시면 대응 시점과 범위가 사전에 정해져 있어, 다시 처음부터 개발자를 찾아 헤매실 필요가 없습니다. 재실행·스케줄링·수집 후 데이터 정제(정제 규칙 조정)는 계약 없이도 GUI에서 언제든 직접 하실 수 있습니다.

**Q. Retrix, 바티AI 같은 가격 모니터링 SaaS도 있던데, 왜 굳이 맞춤 제작인가요?**
표준 SaaS는 범용 사이트 위주로 커버하기 때문에, 특정 도매몰이나 경쟁사 자사몰처럼 구조가 특이한 사이트는 대응이 안 되는 경우가 있습니다. 맞춤 제작은 어떤 사이트든 구조를 분석해 맞춰드릴 수 있고, 프로그램과 수집된 데이터가 전부 고객님 소유라 구독을 해지해도 접근이 끊기지 않습니다. GUI로 직접 수집 조건과 스케줄을 조정하실 수 있다는 점도 차이입니다.

**Q. 제 컴퓨터에서도 실행할 수 있나요?**
네. Windows 실행 파일(.exe) 형태로 납품해 드리며, 별도 서버 없이 사용하시는 PC에서 바로 실행하실 수 있습니다.

**Q. 법적으로 문제는 없나요?**
공개적으로 열람 가능한 데이터를 대상으로 진행합니다. 다만 대상 사이트의 이용약관상 상업적 목적의 자동 수집이 제한되어 있는 경우 진행이 어려울 수 있어, 계약 전에 확인해 드립니다.

**Q. 수집한 데이터를 다른 프로그램(엑셀, 자체 시스템 등)과 연동할 수 있나요?**
네, CSV 또는 DB(SQLite) 형태로 저장되므로 엑셀에서 바로 여시거나 기존 시스템에 연동하실 수 있습니다.
