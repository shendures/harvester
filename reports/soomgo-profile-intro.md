## 한 줄 소개

> 사이트 구조가 바뀌어도 방치되지 않는, 유지보수 SLA를 갖춘 가격·상품 모니터링 프로그램

## 소개글 본문

안녕하세요. 웹사이트에서 필요한 데이터를 자동으로 수집하는 맞춤형 프로그램을 개발해 드립니다.

**이런 경우에 도움을 드릴 수 있습니다**
- 스마트스토어 등에서 경쟁사·거래처 가격, 상품 정보를 매번 수작업으로 확인하고 계신 분
- 도매업자분들처럼 특정 사이트 데이터를 정기적으로(매일/매주/매월) 모니터링해야 하는 분
- 로그인이 필요하거나 JS로 동작하는 사이트라 일반적인 노코드 크롤링 툴로는 해결이 안 되는 분

**다른 곳과의 차이점**
- 한 번 쓰고 버리는 스크립트가 아니라, 납품 후에도 프로그램(GUI)으로 직접 재실행·스케줄링·수집 조건 조정이 가능합니다. 코딩을 모르셔도 계속 운영하실 수 있습니다.
- 정적 HTML, JS 렌더링 사이트, REST API(JSON), XML까지 폭넓게 대응합니다.
- 로그인 인증이 필요한 사이트도 지원합니다.
- 대상 사이트 구조가 바뀌어 손봐야 할 일이 생기더라도, 계약에 명시된 유지보수 정책으로 대응 시점과 범위를 미리 정해드립니다. 저가 단건 작업에서 흔한, 담당자와 연락이 끊겨 방치되는 일이 없습니다.
- (참고) 여러 사이트를 동시에 모니터링하는 통합 프로그램은 현재 준비 중입니다. 지금은 사이트 1개 기준으로 제작해 드리고, 사이트가 여러 개 필요하시면 사이트별로 별도 제작해 드립니다(추가 사이트는 할인 적용).

**가격대 안내**
사이트 구조 난이도에 따라 120만원대(로그인 불필요, 단순 사이트)부터 300만원대(로그인·정기수집·강한 차단 대응 포함)까지입니다. 몇 줄짜리 데이터를 한 번만 빠르게 긁어오는 초저가 단건 작업보다는, 계속 운영하실 프로그램이 필요하신 분께 맞는 가격대입니다. 개발 완료 후에는 월 5만원대부터 유지보수 계약으로 사이트 구조 변경 대응을 받아보실 수 있습니다.

**진행 방식**
요구사항 확인 → 견적 → 개발 → 결과물 검수 → 프로그램 + 사용 매뉴얼 납품 → 하자 보수 → (필요 시) 유지보수 계약

**이런 경우는 다른 전문가분이 더 적합할 수 있어요**
- 법적으로 수집이 제한된 개인정보·저작권 데이터
- 딱 한 번, 몇 줄 데이터만 빠르게 필요하신 초저가 단건 작업

대상 사이트와 원하시는 수집 방식을 말씀해 주시면, 실제로 가능한지와 예상 기간을 확인해서 안내해 드리겠습니다.

## 작성 의도 (내부 참고, 프로필에는 넣지 않음)

- "이런 경우에 도움을 드릴 수 있습니다"에 1차 타겟(스마트스토어 셀러, 도매업자)을 첫 두 줄에 배치해 검색·매칭 시 노출 우선순위를 유도.
- 차별점 항목은 `product-marketing.md`의 Differentiation 섹션 문구를 그대로 반영. **(2026-08-11)** 이 주장은 이제 velog 개발자 후기·hashscraper 비교가이드·클리앙 게시글 3개 독립 소스로 뒷받침되는 HIGH CONFIDENCE 주장이므로("저가 프리랜서는 유지보수 부담에 판매 중단·연락 두절되는 경우가 실제로 많음"), 자신 있게 단정형으로 서술.
- **(2026-08-11 추가)** 멀티사이트 미지원 고지 문구 추가 — 코드 확인 결과(`guidelines/ISSUES.md` 이슈 ⑯) 현재 프로그램 1개당 사이트 1개만 지원되므로, "여러 경쟁사를 한번에" 같은 과장된 인상을 주지 않도록 명시적으로 제약을 밝힘. 과장보다 신뢰가 우선.
- **(2026-08-11 추가)** 가격대 문단 신규 추가 — `product-marketing.md` v5 가격 구조(Starter 120만~Advanced 350만, 유지보수 월 5만~) 반영. 구체적 티어명·패키지 상세는 숨고 프로필 특성상 생략하고 범위만 안내(정확한 패키지는 크몽 gig 참고, `reports/kmong-gig-listing.md`). 가격을 숫자로 명시해 저가 세그먼트를 스스로 걸러내도록 유도(Anti-persona 반영).
- 유지보수 SLA 문구는 "재의뢰가 없다"가 아니라 "재의뢰가 생겨도 방치되지 않는다"는 정확한 주장만 담도록 표현(과장 방지, v3 정정 사항 반영). "재의뢰 없음", "가장 저렴한" 류 문구는 의도적으로 사용하지 않음(Words to avoid, product-marketing.md v4 참고).
