# DataCrawler v2.0 (Harvest)

> Scrapy 크롤링 엔진과 PyQt6 GUI를 결합한 Windows 데스크톱 웹 데이터 수집 프로그램입니다. 비개발자도 코드 없이 수집 조건을 설정해 실행하고, 결과를 CSV·JSON 파일이나 DB로 저장할 수 있습니다.

## 목적과 범위

- 해결하려는 문제: 사이트마다 수집 코드를 새로 작성하지 않고, 설정(블루프린트)만으로 웹 데이터를 수집·정제·저장한다. 수집 의뢰 접수부터 납품·유지보수까지의 사업 프로세스는 [WORK_FLOW.md](WORK_FLOW.md)에 정리돼 있다.
- 대상 사용자: 수집 프로그램을 납품받아 쓰는 고객(비개발자 포함)과, 고객별 수집 조건·커스텀 규칙을 준비해 빌드하는 개발자.
- 제공하는 범위
  - 수집 형식: HTML(정적·Selenium 렌더링), JSON API, XML, 목록→상세 2단계 수집
  - 저장 형식: CSV·JSON 파일, MongoDB·MySQL·PostgreSQL
  - Windows용 exe와 설치 프로그램 빌드 스크립트
- 제공하지 않는 범위
  - 블루프린트 작성은 앱 밖의 오프라인 도구(`generator_conditions.html`)와 DB가 맡는다. 앱 안에는 작성 화면이 없다.
  - 로그인이 필요한 사이트는 Selenium 렌더링 수집(`html_render`)에서만 지원한다.
  - 스케줄 실행에서의 로그인 수집은 미구현이다([ISSUES.md](ISSUES.md) ㉙ 보류).
  - 자동화 테스트 코드는 없다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 수집 조건 설정과 실행 | GUI에서 수집 조건을 확인·조정하고 시작·중지한다. 수집 대상(블루프린트)이 1개면 단일 화면, 2개 이상이면 다중 화면이 열린다. |
| 실시간 모니터링 | 진행률, 수집된 행, 세션 현황, 로그를 수집 중에 확인한다. |
| 데이터 정제 | 결측 행 제거·공백 정리·중복 제거·제외 필드·결측값 치환·숫자 변환을 규칙별로 켜고 끈다. 정제 전후를 나란히 비교한다. |
| 사이트별 확장 | 사이트(seq_no)별 로그인·렌더링·정제 로직을 파일로 추가한다. 앱 코드를 고치지 않는다. |
| 저장 | 수집·정제 결과를 CSV·JSON 파일 또는 DB로 저장한다. |
| 스케줄 | 반복 실행을 등록해 무인으로 수집·정제·저장한다. 스케줄별로 정제 규칙을 지정한다. |
| 세션 설정 | User-Agent·쿠키 랜덤화, 프록시 목록과 상태 점검을 설정한다. |
| 인증 관리 | 로그인 정보를 입력해 로그인이 필요한 사이트를 수집한다. |
| 통계 분석 | 응답 이력으로 KPI를 보여 주고, 수집 상태를 신뢰구간과 회차 패턴으로 평가해 양호·주의·문제로 알려 준다. |
| 시스템 트레이 | 창을 닫아도 백그라운드에서 스케줄이 이어지고, 실패는 트레이 알림으로 알린다. |
